# Catálogo — Tipo de pasaporte / documento de viaje (`ddlPPT_TYPE`)

**Campo:** `ctl00_SiteContentPlaceHolder_FormView1_ddlPPT_TYPE` — pantalla
`PptVisa` ("Passport/Travel Document Type"). Corresponde a la variable
`tipoDocumentoPasaporte`.

6 opciones (incluye el placeholder). **Dispara postback**: con `T` (OTHER)
aparece un campo de texto para especificar el tipo.

Formato: `value|texto en inglés (DS-160)|traducción al español`.

```
|-Select One-|(sin seleccionar)
R|REGULAR|Regular (ordinario)
O|OFFICIAL|Oficial
D|DIPLOMATIC|Diplomático
L|LAISSEZ-PASSER|Salvoconducto (laissez-passer)
T|OTHER|Otro
```
